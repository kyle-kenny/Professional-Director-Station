# Standard Director Cast

PDS ships a license-safe procedural greybox cast so blocking never depends on third-party character licensing.

Baseline presets:

1. 男童 / boy child
2. 女童 / girl child
3. 少年 / teenage boy
4. 少女 / teenage girl
5. 成年男 / adult man
6. 成年女 / adult woman
7. 老年男 / elderly man
8. 老年女 / elderly woman

Each preset carries explicit directing dimensions: age group, age, standing height, eye height, shoulder width, body depth, head radius and posture. 3D silhouettes are generated from these values, so camera height, eyelines, framing and spatial relationships differ correctly between children and adults instead of merely recoloring one mannequin.

Future character assets may replace the greybox visual while preserving the same actor ID, transform, eye-line, pose, path and demographic directing dimensions. External models must pass asset/version/license/unit checks before entering the production library.
