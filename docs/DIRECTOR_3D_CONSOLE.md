# PDS 3D 导演台与灯光台

PDS 1.1 将 3D 工作区从单纯的场景视口继续收束为导演可直接操作的场面调度台。界面方向参考轻量化虚拟制片 / 3D 导演工具常见的“左侧场景对象 + 中央 3D 舞台 + 右侧精调 + 底部快速对象架”工作流：导演先用少量高频操作完成构图、人物调度和摆灯，再进入 Inspector 做精确参数调整。

## 场景对象

进入 3D 导演台后，左侧直接列出当前摄影机、每个人物和每盏灯。人物与灯光都可从对象树选中，并与中央 3D 视口、右侧 Inspector 保持同一选择状态。

## 灯光台

3D 视口底部提供常用灯具架：

- 主光：区域光，默认位于摄影机左前方。
- 补光：区域光，默认位于摄影机右前方且强度更低。
- 轮廓光：聚光灯，默认位于人物后侧。
- 聚光灯：通用可定向硬光。
- 点光源：全向局部光源。
- 太阳：平行光。
- 环境光：无方向整体基础照明。

新增灯具的位置不是固定世界坐标，而是根据当前帧的摄影机方向和演员舞台中心自动计算，因此镜头换位后仍能快速得到可用的主 / 补 / 轮廓关系。

选中任意非环境灯后，灯光台还提供“左 / 上 / 右 / 前 / 下 / 后”六方向快速布光。方向是相对于当前摄影机和人物舞台中心计算的，点击后会真实移动灯具世界位置；聚光、平行光和区域光同时重新瞄准人物中心。快速方向用于 blocking，之后仍可用 3D 操纵器和 Inspector 精调。

## 3D 操作

新增灯具自动选中。非环境光灯具在 3D 视口中显示灯具标记；点光、聚光、平行光和区域光均驱动真实 Three.js 光源。灯具位置使用与人物场面调度相同的 TransformControls，修改会进入工程 Undo / Redo。

右侧 Inspector 继续负责精调：

- 强度
- 色温
- 世界位置
- 目标位置
- 阴影
- 灯光关键帧

底部灯光台提供“六方向布光”“瞄准人物中心”“当前帧关键帧”“复制灯具”“删除”等高频动作。

## 制作约束

- APPROVED 镜头中的新增、复制、删除、移动与参数编辑全部保持只读。
- 灯光编辑写入 Shot 数据模型，不是仅存在于 Three.js 临时状态。
- 有灯光关键帧轨时，参数调整与六方向 blocking 都遵守帧权威时间线。
- 区域光和环境光不伪造 Three.js 当前 WebGL 路径不支持的实时阴影能力。
- 3D 灯光台由 Windows / Ubuntu 静态审计、Vitest Light Schema 回归和 Chromium 用户旅程共同验证。
