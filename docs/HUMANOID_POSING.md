# PDS 1.1 Humanoid 人物调姿规范

PDS 1.1 的人物调姿直接作用于 Quaternius Universal Base Characters 的真实 SkinnedMesh / Humanoid 骨骼，不再使用程序化人体几何。

## 导演级 FK 控制

可编辑 20 个主要人体关节：骨盆、腰椎、胸椎、上胸、颈部、头部、左右锁骨、上臂、前臂/肘、手腕、左右大腿/髋、小腿/膝和脚踝。

每个关节使用导演安全的附加旋转范围。数值输入、滑杆和 3D 旋转操纵器都必须经过相同的关节极限裁剪，避免预演阶段出现明显反关节或肢体折断。

## 手脚 IK 与 Pole

四条 IK 链：左手臂、右手臂、左腿、右腿。每条链包含末端目标和弯曲方向 Pole：

- 手部目标控制手的位置；肘部 Pole 控制肘部朝向。
- 脚部目标控制脚的位置；膝部 Pole 控制膝部朝向。
- 两段式 IK 使用真实骨段长度，不允许伸长骨骼；不可达目标被夹到最大/最小可达范围。
- FK 与对应 IK 互斥：IK 开启时，该链的主要 FK 关节隐藏并禁止直接编辑。

## 手脚目标锁定

“锁定目标”用于冻结当前 IK 目标，阻止误拖和数值改写。后续世界空间锁定语义由运行时保存的锁定世界目标实现，使演员根位移时手/脚仍可固定在布景接触点。

## 头部与视线目标

头部注视目标控制颈部/头部朝向，并限制水平和俯仰角，避免超出人体合理范围。当前开源角色包没有独立眼球骨骼，因此 PDS 将“视线目标”定义为头部/面部朝向目标，不虚构不存在的眼球骨骼控制。

## 3D 操作

进入“人物调姿”后：

- 蓝色：FK 关节。
- 绿色：IK 末端目标。
- 橙色：肘/膝 Pole。
- 黄色：头部注视目标。

FK 使用旋转 Gizmo；IK、Pole、注视目标使用移动 Gizmo。拖动过程中实时预览骨骼求解，鼠标松开时只提交一次工程历史记录，保证 Undo / Redo 可预测。

## 姿势关键帧

人物位移轨与骨骼姿势轨相互独立：

- 首个姿势关键帧建立 `posePath`。
- 此后 FK、IK、Pole、注视编辑自动写入当前整帧。
- FK 使用最短角插值；IK/Pole/注视目标使用空间插值。
- 时间线可以定位、新增和删除姿势关键帧。

## 自定义姿势与镜像

当前人物完整 Rig 状态可以保存为工程级自定义姿势，应用到兼容 Humanoid 人物。左右镜像会交换左右 FK/IK 链并镜像目标位置与旋转方向。

## 审批与协作

所有调姿变更进入统一 Project 历史、实时协作和不可变 Shot Version。`APPROVED` 镜头在本地和服务器权威层均只读，必须先从审片工作区重新打开为新的制作中版本后才能改姿势。

## AI 可追溯结构控制

AI Control Bundle 记录当前帧人物根变换、Humanoid Rig 状态和 Rig 哈希，使 Storyboard / Video 请求可以追溯到具体 Shot Version、帧和骨骼控制状态。
